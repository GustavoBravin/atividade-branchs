# Meu Projeto Simples

Um site básico feito com **HTML, CSS e JavaScript** para praticar Git e GitHub.

## 📁 Estrutura do projeto

```
atividade-branchs/
├── index.html      # Página principal
├── style.css       # Estilos do site
├── script.js       # Interatividade (contador de cliques)
├── error.txt       # Anotações de erros encontrados e soluções
├── README.md        # Este arquivo
└── img/
    ├── foto1.png
    ├── foto2.png
    └── foto3.png
```

## 🚀 Como visualizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

## 🛠️ Tecnologias usadas

- HTML5
- CSS3 (flexbox, gradientes, hover)
- JavaScript (manipulação do DOM, eventos de clique)

## ✨ Funcionalidades

- Galeria com 3 imagens de exemplo.
- Botão interativo que conta os cliques usando JavaScript.

## 📝 Sobre

Projeto criado como exercício de Git/GitHub, incluindo commits de criação,
edição e remoção de arquivos.
